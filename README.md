# Academic personal website (GitHub Pages)

Three pages: About (`index.html`), Publications (`publications.html`), CV (`cv.html`). No build step.

## Publish
1. Create a public repo named `YOUR-USERNAME.github.io` and upload everything in this folder to its root.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Live at `https://YOUR-USERNAME.github.io` in a minute or two.

## Edit
- Bio, news, CV: edit the HTML files.
- Publications: edit the list in `pubs-data.js` (add links like `links: { PDF: "https://..." }`).
- Photo: save as `assets/photo.jpg` (initials show until then).
- CV file: `assets/cv.pdf`. Colors and fonts: top of `style.css`.
- Social links: the list in `index.html`.
